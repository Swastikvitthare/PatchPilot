Usage Tips

  • 1Paste Python code or upload a .py file to scan for vulnerabilities.
  • 2PATCHPILOT never executes your code — all analysis is done via AST parsing.
  • 3Use the Re-scan feature to verify that patches eliminate the detected flaw.
  • 4Download the security audit report to share findings with your team.
  • 5Gemma 4 provides plain-language explanations and targeted remediation for each CWE.
